# Adtech Startup Radar

A public-source, interactive scan of private adtech companies across targeting, optimization, measurement and commerce.

The site deliberately distinguishes ARR, annual revenue, run-rate, transaction value and estimates. It is a research snapshot, not investment advice.

## Local preview

Serve this directory with any static HTTP server, then open `index.html`.

## Data maintenance

Company records and source links live in `data.js`. Update the `asOf` field and evidence label whenever a financial figure changes.
